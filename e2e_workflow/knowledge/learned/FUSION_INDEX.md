directory). It holds exactly one group, `## kernel fusion`, which `scripts/fusion_priors.py`,
`fusion_screen.py` and `fusion_candidate_harness.py` read as the prior denominator: every card here
needs an explicit disposition in Phase 2.1. The shared `INDEX.md` is the e2e workflow's and is not
read or written by KernelFusion. Card format and confidence stars: see `README.md`.
